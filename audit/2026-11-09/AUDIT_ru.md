## 3. Критично — требует решения владельца (RED)

**Режим владельца БД включается автоматически.**
FACT (код v19/v21, функция выбора режима): если конектор «TERZI ERP» не подключён, режим = `owner` без условий; ветка `none` недостижима. В режиме `owner` браузер выполняет SQL через конектор Neon `run_sql` (роль `terzi_dev_owner`, BYPASSRLS), включая `insert/update` (синхронизация документов, 12 SQL-записей в коде).
FACT: кнопка «Увімкнути режим власника БД (тимчасово)» вызывает только `confirm()` и ничего не включает.
Противоречие: REPORT_ru от 26.10, P0 — «режим владельца БД — только явным включением». Код этому не соответствует.
RISK: любой сеанс владельца без ключа шлюза работает с полными правами; RLS и проверки сервера обходятся.
Готовое исправление: `build/terzi-erp-v21-security-candidate.html` — по умолчанию `none`, включение только кнопкой (флаг в браузере), добавлена кнопка «Вимкнути режим власника БД». Проверено эмуляцией.
Последствие для владельца: пока ключ «TERZI ERP» не подключён, legacy-экраны покажут «Немає доступу» до явного включения режима.
DECISION нужна: публиковать или нет.

## 4. Ядро расчётов и сметы

- golden 67/67 PASS: деньги (M), округление, калькуляторы-шаблоны (CS-*), наценка ≠ маржа, стяжка/ПВХ/рубероид/утепление, тарифы.
- `calc.ts`: суммы в копейках, `MissingRef` при отсутствии нормы или ставки; граница тарифа строго `> 100 м²`.
- ASSUMPTION в коде: если для «>100 м²» цена работ (`sellGt100`) или ставка бригады (`pieceRatesGt100`) не задана, молча берётся цена «≤100». Рекомендация: показывать предупреждение в смете.
- Расчёт и фиксация сметы на сервере (`gw_exec`) — по коду; вживую не проверено.
- Данные: опубликованных реальных прайсов нет; 18 пустых норм и 3 допущения (из REPORT_ru, не перепроверено).

## 6. Архитектура и интеграции (по коду)

- Один HTML-бандл 1,86 МБ (JS 1,6 МБ, React 19.3), без исходников части разделов (Калькулятори, Каталог, Воронки, Дзвінки, Ціни, ChatDock и др.). Правки v20–v21 сделаны в бандле; их нужно перенести в исходники.
- Пути данных: (1) шлюз «TERZI ERP» MCP — защищённый, команды + `legacy_select`; (2) Neon `run_sql` — прямой SQL (см. п. 3); (3) хранилище claude.ai `db` / localStorage — локальный режим; (4) FinMap MCP — прямое чтение.
- В клиенте: 106 SQL-литералов `select`, 217 ссылок на 84 объекта `erp4.*`. Схема БД зашита в браузерный код → любое изменение схемы ломает UI.
- Артефакт доступен «всем по ссылке». Данные защищены конекторами зрителя, но код со схемой БД виден всем.
